# vlessCDN
vless+ws+tls套CDN

🪶 方法一：用 wget 直接下载（推荐）

在你的 Linux 服务器上执行以下命令：

wget https://raw.githubusercontent.com/juzi737/vlessCDN/main/nogwfipvless.sh


然后赋予执行权限：

chmod +x nogwfipvless.sh


执行脚本：

sudo ./nogwfipvless.sh


✅ 这是最简单、最常用的方式。
下载的就是 GitHub 上的原始 .sh 文件，没有多余文件。

🧩 方法二：用 curl 下载

如果你的系统没有 wget，也可以用 curl：

curl -O https://raw.githubusercontent.com/juzi737/vlessCDN/main/nogwfipvless.sh


同样再执行：

chmod +x nogwfipvless.sh
sudo ./nogwfipvless.sh
